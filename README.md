## Dara engineering refresher

### To be a decent data engineer, one should know what the below is and how it applies in the real world to handle data,

  * Extract, Load and Transform recepies
  * OLTP and OLAP
  * Star and Snowflake schema structures
  * Fact and Dimention tables
  * Keys - primary, foreign and surrogate
  * Slow changing dimensions
  * Schema evolution
  * Handling late arriving data
  * Partitioning, handling large datasets and indexing
  * Medallion architecture
  * Data warehouses, data lakes and lakehouse
  * Batched and streaming pipelines
  * Orchestartion
