## Online Transaction Processing (OLTP)

Online Transaction Processing (OLTP) systems are designed to manage, record, and update real-time, day-to-day business transactions such as ATM withdrawals, online purchases, banking transfers, and booking systems.
These systems typically use highly normalized databases to ensure fast transaction processing, strong data integrity, and efficient concurrent access. OLTP databases are optimized for frequent reads and writes of small amounts of data, often using row-oriented storage.

OLTP systems also follow ACID properties to guarantee reliable and consistent transactions.

---
### Key Characteristics : 

#### High Concurrency :
OLTP systems are built to support thousands of simultaneous users and transactions. Multiple users can read and modify data concurrently without compromising consistency.

#### Fast Response Times :
They are optimized for rapid execution of small, simple transactions, typically completing in milliseconds to support real-time applications.

#### ACID Compliance :
OLTP systems enforce ACID properties to ensure data reliability:

  * Atomicity – Transactions either complete fully or not at all.

  * Consistency – Data remains valid and follows all constraints after a transaction.

  * Isolation – Concurrent transactions do not interfere with each other.

  * Durability – Once committed, data changes persist even in case of system failure.

#### Normalized Data Models :
OLTP databases usually follow Third Normal Form (3NF) to:

  * 1NF - Every cell contains a single (atomic) value and there are no repeating groups of columns.
  * 2NF - A table is in 2NF if it is in 1NF and all non-key attributes are fully dependent on the entire primary key.
  * 3NF - A table is in 3NF if it is in 2NF and all non-key attributes are dependent only on the primary key, there is no transoitive dependency.

#### Row-Oriented Storage :
Data is typically stored row by row, which allows efficient retrieval and modification of individual records during transactions.

---
#### Common OLTP Systems :
Examples of widely used OLTP databases include:

  * MySQL
  * PostgreSQL
  * Oracle Database
  * Microsoft SQL Server

These systems are commonly used in applications such as banking platforms, e-commerce systems, reservation systems, and inventory management systems where fast, reliable transactions are essential.
